# Ultra 0.1.4 验证

2026-11-06，北京时间。

- Ultra 构建和 13 项单元测试通过。新增宿主测试覆盖当前步骤团队工具可见性变化、Ultra 关闭后移除指令、真实 Max 参数保持；协议边界使用测试替身。
- 仓库统一兼容策略检查通过；10 个插件的官方兼容门禁共 20 项测试通过。发布分支保留 `>=0.2.1-rc.3 <0.3.0-0` 声明，未来宿主 API 未逐版验证。
- 本机 DSH 0.2.2-rc.1 的已启用 Ultra 会话日志中，系统消息包含 `Ultra mode: proactively delegate using DeepSeek native Agent Teams` 与 `MUST call spawn_teammate`，后续记录了共享任务板操作和两次 `spawn_teammate` 调用。
- 另一条未启用 Ultra 的会话系统消息没有 Ultra 指令，符合按聊天保存模式的设计。安装或开启团队插件本身不自动开启 Ultra。

实际日志证明该次会话注入和调用发生，不证明模型始终先委派、稳定遵循所有要求，或团队执行质量提高。此功能通过系统提示词要求团队协作，没有新增调度器硬拦截，仍遵守用户更具体的指令及宿主权限、容量、审核和取消规则。
